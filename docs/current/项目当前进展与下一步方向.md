# 项目当前进展与下一步方向

更新时间：2026-08-04

本文根据 `docs/` 中的工程与验证记录，以及 `pipelines/` 中的仿真和重建文档整理。它用于快速说明项目目前走到哪里、已经证明什么、尚未证明什么，以及下一步应优先推进哪些工作。

## 1. 总体判断

项目已经完成两条关键前置主线：

1. **仿真科学假设已通过。** 短轨迹和长轨迹实验均支持动态三维人体—手机相对几何 `r_t` 会显著改变复 CSI，并会污染静态环境参数估计；只使用标量距离 `d_t` 不足以描述这一影响。
2. **手机—UDP—CSI 最小工程闭环已通过。** iPhone 原生 App 已能在同一进程、同一手机单调时钟下同步记录视频、ARKit、IMU 和 UDP；Linux/PicoScenes 已能筛出同一时段的手机上行 CSI，并完成长时钟漂移估计。

项目当前已从“验证能否采集和是否值得研究”进入“建立可重复、可标定的统一数据闭环”阶段。下一步的核心不是继续扩展采集功能，而是完成 CSI 时间轴物化、人体几何标定、跨 session 重复性、房间重建和统一坐标，随后进入真实数据下的参数反演。

```text
已完成：科学假设 + 手机多模态采集 + 手机上行 CSI + 初步时钟映射
    ↓
当前重点：可信同步 + 重复性/校准 + 人体几何真值 + 房间模型
    ↓
后续目标：统一数据集 + 真实 CSI 条件下的可微射线追踪闭环
```

## 3. 已完成工作的关键证据

### 3.1 仿真侧

- 阶段 1 短轨迹实验完成 960 个主体几何求解，机器结果为 `overall_go=true`。
- 忽略动态三维几何时，测试复 NRMSE 为 `0.886097`；使用真值三维几何后降至 `0.000613`。
- 使用带噪三维深度时，测试误差相对固定几何降低约 93.9%。
- 只保留正确距离、但使用错误方向时仍然失败，说明 `d_t` 不能替代三维 `r_t`。
- 长轨迹实验覆盖 80 个时刻和 5 个空间区块，完成空间留一交叉验证；小径向误差、方向误差、联合误差和突发异常的主要 Go 判据均通过。
- 错误人体几何会系统性推动有效反射参数偏离真值，证明几何错误可能被静态参数吸收。

这些结果支持继续以动态三维人体几何为研究主线，但不等同于真实人体、真实硬件或完整电磁传播已经验证。

### 3.2 手机与 CSI 工程侧

- iPhone 11 Pro 已通过 ARKit 世界跟踪、用户人脸跟踪、CoreMotion、真机签名与采集能力验证。
- P1 的 1 分钟测试完成 3583 个视频/ARKit 帧、约 4.2 万条 IMU 样本，视频丢帧和位姿映射缺失均为 0；该次测试的人脸有效跟踪率为 99.81%。
- 150 秒独立 UDP/CSI 测试中，Linux 接收率为 99.8336%，筛得 1535 个手机上行大包 CSI PPDU。
- 长时拟合得到约 `-18.457 ppm` 的手机—CSI 时钟漂移，当前可靠性判据已通过。
- 60 秒 Recorder 同进程测试同步生成 3569 个视频/ARKit 帧、42038 条 IMU、12481 个成功 UDP 包及 191 个筛选 CSI PPDU，视频丢帧为 0。
- UDP、ARKit 和 IMU 已证明使用同一 App 进程内的手机单调时钟；CSI 设备时钟则通过 Linux 内核时间桥接。

当前时钟桥仍属于软件同步，残差包含网络排队、Wi-Fi 聚合和非一一对应关系，不能表述为硬件同步或逐包精确配对。

## 4. 当前尚不能声称的内容

- 不能声称商品 CSI 的跨 session 绝对相位已经可比；相位校准尚未完成。
- 不能声称原生 WiTwin/RayD 反射 EPC 已通用通过。现有多阶反射实验使用的是显式 DrJit 后端。
- 不能声称前置传感器已经准确测得胸腔位置；目前验证的是人脸锚点采集能力，人体参考点仍需外部真值标定。
- 不能声称已有可用于射线追踪的真实房间模型；重建流水线目前只有设计文档。
- 不能声称真实数据上的深度条件参数反演已经有效；这一结论仍依赖统一数据集与受控实验。
- 不能把稳定器条件下的结果外推到任意自然手持、人员、衣物和装配状态。

## 5. 下一步方向

### P0：先完成可信的多模态数据闭环

1. 实现离线时间轴物化工具，将每条 CSI 的设备时间转换到手机单调时间，并关联最近的 ARKit 帧和 IMU 时间区间。
2. 在 session 元数据中记录时钟映射文件、SHA-256、设备组合、日期和适用范围，禁止跨设备或跨日期误用漂移参数。
3. 在相同静止位置重复至少 3 个 60 秒联合 session，统计 UDP 接收率、CSI 采样密度、时间映射残差和跨 session 稳定性。
4. 冻结手机—夹具—稳定器和网卡—天线—主机装配，并在每次采集前后保存静态参考段。
5. 相位校准独立推进；在完成前，真实主实验优先使用幅度、RSSI、包级时间和可靠的相对特征。

P0 完成标志是：任一 CSI 样本都能追溯到手机时间、对应位姿/IMU、设备装配、时钟映射版本和原始数据。

### P1：补齐人体几何与房间几何

1. 完成前摄像头—Wi-Fi 天线外参和人脸—胸腔参考点标定，并使用侧拍、测距或外部深度设备提供独立真值。
2. 建立人体几何的 RAW/KF/RTS 基线，输出三维 `r_t`、距离 `d_t`、质量标志和协方差；重点验证动态误差、掉帧恢复和协方差可信度。
3. 启动 COLMAP/SfM 重建基线：关键帧选择、视觉轨迹、与 ARKit 米制轨迹的 SE(3)/Sim(3) 对齐、稠密点云和网格化。
4. 使用独立测距检查房间尺度、墙面平整度、夹角、网格完整率和重复扫描一致性。
5. 对房间主要传播表面进行材料区域标注，并把手机轨迹和 CSI 接收天线放入同一房间坐标系。

P1 完成标志是：得到经过外部精度检查的人体轨迹和房间模型，而不仅是可视化结果。

### P2：进入真实无线数字孪生闭环

1. 建立统一数据加载器，读取 CSI、手机位姿、人体几何、房间网格、材料区域、装配配置和时间映射。
2. 先在固定人员、衣物和稳定器装配下采集受控数据，分离 `w_geo`、硬件漂移、装配变化和人体属性误差。
3. 比较固定人体、原始深度、KF、RTS 和不确定度边缘化方法；优先使用低维、已通过梯度检查的环境参数。
4. 预先划分训练轨迹、留出轨迹和留出 session，主要报告测试残差与跨 session 参数一致性，而不是只报告训练误差。
5. 在真实主线稳定后，再扩展不同人员、衣物、AP 位置、房间和自然手持压力测试。

## 7. 主要风险与处理原则

- **时间同步残差过大**：缩短 session、降低运动速度，使用前后静态段并继续改进时钟桥；不把最近邻匹配当作严格逐包对应。
- **相位不可用**：先做幅度与相对特征；相位校准未通过前不用于主要结论。
- **无 LiDAR 房间重建不稳定**：改进扫描路径和纹理条件；必要时借用 LiDAR 设备作为辅助真值，但不改变主线数据定义。
- **人脸不能稳定代表胸腔**：引入个体标定、头部姿态或肩部关键点，并把残余误差传播为协方差。
- **仿真与真实差距过大**：分别检查房间几何、有效天线响应、射频链、人体模型和材料参数，不把全部残差归因于人体几何。
- **参数不可辨识**：第一轮只优化 1–2 个参数，使用无人/固定装配数据锚定，并检查有限差分梯度和留出数据泛化。
