# `work/ios-recorder` 分支当前状态

更新时间：2026-08-04

## 当前结论

P0 真机环境、P1 单手机采集功能闭环和 P2 Recorder 同进程 UDP 联合采集均已通过。iPhone 11 Pro 可以在同一 App 进程和手机单调时间基准下记录后置视频、ARKit 位姿、IMU、人脸锚点和 UDP 发送日志。

已验证的代表性结果包括：

- 1 分钟 P1 session 中视频和 ARKit 各 3583 帧，视频丢帧与位姿映射缺失均为 0；
- IMU 各流约 100 Hz，该次人脸有效跟踪率为 99.81%；
- 60 秒 P2 联合 session 中视频、ARKit、IMU 和 UDP 同期运行，完整性检查通过；
- 采集 App、schema、校验和和离线检查脚本已经形成基础闭环。

## 当前缺口

- 人脸锚点尚未通过外部真值换算为可靠的胸腔/人体参考点 `r_t`；
- 前摄像头—Wi-Fi 天线外参、头部姿态影响和人体几何协方差尚未完成标定；
- 正式移动房间扫描和更长压力测试仍需在 P3 数据需求明确后执行；
- iPhone 11 Pro 没有后置 LiDAR，房间模型必须依赖后置视频、ARKit VIO 和离线重建。

## 下一步

1. 冻结手机—保护壳—夹具—稳定器装配编号和相机采集配置。
2. 完成人脸—胸腔和相机—天线外参标定，并采集独立真值。
3. 为 CSI 时间轴物化输出稳定的 ARKit/IMU 查询接口和缺失区间标志。
4. 按 P3 扫描规范采集至少一段完整房间轨迹，并保存质量事件与校验和。
5. 保持原始观测与滤波结果分离，不在手机端伪造统一时钟或人体真值。
