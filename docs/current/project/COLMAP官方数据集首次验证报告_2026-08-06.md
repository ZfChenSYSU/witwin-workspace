# COLMAP 官方数据集首次验证报告

日期：2026-08-06  
平台：Windows 笔记本 WSL2 + Docker  
结论：通过

## 1. 验证目标与范围

本次目标是回答一个明确问题：RTX 4050 Laptop 6 GB、16 GB 内存的笔记本环境，能否
不依赖现成 COLMAP 数据库或稀疏模型，从原始图片开始跑通完整 COLMAP 基线。

首次测试只使用 COLMAP 官方 South Building 数据集。iPhone 视频不属于本次 COLMAP
验收输入；iPhone 端工作仅保留独立的采集格式和导入检查结果。

验收流水线：

```text
原始图片
  -> 空 database.db
  -> CUDA SIFT
  -> CUDA exhaustive matcher
  -> incremental mapper
  -> image undistorter
  -> CUDA PatchMatch stereo
  -> stereo fusion
  -> PyCOLMAP / Open3D 读取与指标检查
```

## 2. 环境与输入

| 项目 | 配置 |
| --- | --- |
| GPU | NVIDIA GeForce RTX 4050 Laptop，6 GB |
| 主机内存 | 约 9.7 GiB 可供 WSL，另有 16 GiB swap |

| 新工作区 | `/data/testdata/south-building-from-empty-v1` |

下载后的 ZIP 通过 `python3 -m zipfile -t` 完整性检查。本次工作区在运行前不存在，
流水线只读取 `images/`，没有读取数据包附带的 `database.db` 或 `sparse/`。

## 3. 运行配置

核心配置：

- 特征：SIFT，GPU 0；
- 最大图像尺寸：800；
- 每图最大 SIFT 特征：4096；
- 匹配：exhaustive matcher，GPU 0；
- 相机：单 OPENCV 相机；
- 稀疏：incremental `mapper`；
- 稠密：PatchMatch，5 samples、2 iterations、geometric consistency；
- 融合输入：geometric depth maps；
- 最低磁盘余量门槛：30 GiB。

实际命令：

```bash
/opt/witwin-tools/venvs/geometry/bin/witwin-run-colmap \
  --image-path /data/testdata/south-building-source/south-building/images \
  --workspace /data/testdata/south-building-from-empty-v1 \
  --stage all \
  --colmap /opt/witwin-tools/colmap-4.0.4/bin/colmap \
  --matcher exhaustive \
  --mapper mapper \
  --feature-type SIFT \
  --camera-model OPENCV \
  --single-camera \
  --max-image-size 800 \
  --max-num-features 4096 \
  --patchmatch-samples 5 \
  --patchmatch-iterations 2 \
  --minimum-free-gib 30
```

## 7. 能力边界

本报告证明的是笔记本 WSL/Docker/CUDA/COLMAP 软件与硬件链路可以从空数据库跑完
受控稀疏和稠密基线。它不证明：

- iPhone 视频已经进入 COLMAP；
- ARKit 内参已经正确写入 COLMAP；
- ARKit 与 COLMAP 已完成米制 Sim(3) 对齐；
- iPhone 房间扫描已达到稀疏或稠密重建质量；
- 网格、房间平面、材料区域或 WiTwin 场景已经导出。

这些内容均保留为后续阶段，本轮不继续使用 iPhone 视频建模。
