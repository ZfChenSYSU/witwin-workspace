# 前置深度增强科研项目精简执行计划

版本：2026-07-31

依据：以《前置深度增强的科研项目待办与验证计划.md》为主，其他项目文档仅用于补充背景。若存在冲突，以主计划为准。

## 1. 项目目标

验证一条基于商用手机和 CSI 网卡的室内无线数字孪生路线：

1. 手机后摄像头与 IMU 提供手机六自由度位姿和房间重建输入；
2. 手机前置深度或人脸三维跟踪估计人体相对手机的动态三维几何；
3. CSI 采集网卡测量手机通信帧在 `phone -> CSI acquisition NIC` 链路上的 CSI；
4. 将位姿、人体几何及其不确定度输入可微射线追踪，优化墙体材料等静态环境参数 `\theta`；
5. 判断该方案能否在留出轨迹和跨采集轮次条件下稳定工作，并量化其成本与适用边界。

第一阶段使用固定的“手机—保护壳—夹具—稳定器”装配，以控制握持失谐和快速姿态变化。自然手持只作为后续压力测试。

## 2. 核心科学问题

项目需要依次回答四个问题：

1. **人体几何是否重要**：人体—手机距离和方向变化是否会引起稳定、可解释的 CSI 变化？
2. **忽略几何是否产生参数偏差**：使用固定人体位置代替真实动态几何时，误差是否会被环境参数 `\theta` 吸收？
3. **前置深度能否修正偏差**：使用测得的人体三维几何及其协方差后，能否降低留出数据上的 CSI 残差和 `\theta` 偏差？
4. **商用链路是否可用**：整机天线响应、射频链和装配状态是否足够稳定、可校准，使 `\theta` 能跨轨迹、跨 session 恢复？

若前两个问题不成立，人体动态几何不应继续作为论文主线；若第四个问题不成立，则真实系统结论应降级为仿真结果或更换硬件路线。

## 3. 研究对象与边界

手机状态采用六自由度位姿：

```math
\mathbf q_t=(\mathbf p_t,R_t)
```

人体状态优先采用人体参考点相对手机 Wi-Fi 天线的三维向量：

```math
\mathbf r_t=[x_t,y_t,z_t]^T,\qquad d_t=\|\mathbf r_t\|_2
```

其中 `d_t` 只是派生距离；进入真实闭环前，必须比较三维 `\mathbf r_t` 与单一 `d_t` 的效果。

前置传感器通常直接观测人脸，而非胸腔或人体电磁反射中心。因此必须通过“前摄像头—Wi-Fi 天线”和“人脸—胸腔参考点”两级标定获得：

```math
\mathbf z_t^{depth}=\mathbf r_t+\mathbf v_t,\qquad
\mathbf v_t\sim\mathcal N(0,R_t)
```

前置深度主要降低动态几何误差 `w_geo`，不能自动消除体型、衣物、介电属性和精细姿态导致的 `w_human`。硬件漂移、天线装配和传播模型误差也必须分别控制，不能统一归为高斯噪声。

## 4. 总体方法

系统输入包括：

- 手机六自由度位姿 `\mathbf q_t`；
- 人体几何估计 `\hat{\mathbf r}_t` 及协方差 `P_t`；
- 多子载波、多天线复数 CSI；
- 固定并标定的手机端和接收端装配状态；
- 统一坐标系下的房间网格、材料区域和接收天线位置。

可微射线追踪模型为：

```math
\hat{\mathbf s}_t=
F_\theta(\mathbf q_t,\mathbf r_t,
\boldsymbol\beta_t,\mathbf a_t;\mathbf c)
```

算法验证按复杂度递增：

1. `FIXED`：使用固定人体位置，作为基线；
2. `DEPTH-RAW`：直接使用标定后的前摄观测；
3. `DEPTH-KF`：使用质量感知的三维卡尔曼滤波，作为在线主方法；
4. `DEPTH-RTS`：使用离线 RTS 平滑，作为离线参考上限；
5. `DEPTH-MARG`：根据 `P_t` 对人体几何采样并边缘化，作为主要方法创新；
6. `DEPTH-JOINT`：在视觉约束下联合优化人体几何与 `\theta`，仅在前述方法有效后尝试。

普通滤波、鲁棒损失和双摄采集本身不是主要贡献。潜在方法贡献是将动态人体几何及其不确定度显式传播到无线环境参数反演中。

## 5. 执行阶段

### 阶段 0：最小可行性确认

并行完成五项检查：

- 手机能否持续输出后摄世界位姿、前摄人脸三维位姿和可解释时间戳；
- CSI 网卡能否连续输出可识别的手机上行帧 CSI；
- 支架、稳定器和直接手持条件下，整机响应是否具有可接受的重复性；
- 当前射线追踪工具能否计算目标前向模型，并通过参数梯度的有限差分检查；
- 第一阶段手机端、接收端和稳定器装配能否冻结并重复安装。

通过后再扩大软件或硬件开发。当前 WiTwin 组合已验证确定性信道、LOS、CIR 和 CFR，但一次及以上反射路径仍需单独验证。

### 阶段 1：仿真验证科学假设

建立最小房间、手机、接收端和简化人体模型，先优化 1–2 个可解释环境参数。比较：

- 固定人体生成、固定人体优化；
- 动态人体生成、固定人体优化；
- 动态人体生成、真实人体几何优化；
- 带噪深度、滤波深度和不确定度边缘化；
- 标量距离与三维人体几何；
- 理想天线与非理想有效方向图。

只有当忽略动态人体几何会显著增加 `\theta` 偏差，且深度条件方法能在测试轨迹上改善结果时，项目才进入完整人体几何主线。

### 阶段 2：人体几何采集与处理

优先使用 ARKit 世界跟踪与用户人脸跟踪并发路线。通过外部真值完成相机—天线、人脸—胸腔和时间标定，并比较原始观测、简单平滑、三维 KF 与 RTS。

初期目标为：

- 静态距离 MAE 小于 5 cm；
- 95% 距离误差小于 10 cm；
- 自然行走时有效输出率高于 95%；
- 短时丢失后约 0.5–1 s 内恢复。

这些数值是项目门槛，需根据预实验修订，不应表述为传感器固有性能。

### 阶段 3：CSI 链路与整机校准

固定频段、信道、带宽、天线、线缆、支架和采集主机位置，生成稳定手机上行流量，并通过 MAC 与帧方向筛选 CSI。

先验证幅度和 RSSI，再处理 CFO、SFO、PDD、公共相位旋转等误差。若相位无法可靠校准，第一阶段只使用幅度，不声称完整复数 CSI 已验证。

每轮采集前后保留静态参考段，量化跨时间、拆装和 session 的漂移。建立手机—稳定器与网卡—主机的有效方向图或低维方向性模型，并用留出 session 检查其泛化。

### 阶段 4：多模态数据闭环

将 CSI、SLAM、人体几何和外部真值映射到统一时间轴；估计手机与 CSI 主机时钟的偏移和漂移，并按 CSI 包时间插值人体状态。

统一房间、SLAM、手机相机、手机天线、人体和接收天线坐标。准备具有正确尺度、主要传播表面和材料区域的真实房间模型，并确保所有原始数据、滤波结果、质量标志和标定版本可追溯。

阶段完成标志是一段可复现的完整 session：任一 CSI 包都能关联手机位姿、人体几何及其质量、装配配置和房间模型。

### 阶段 5：深度条件的参数反演

先在合成数据中完成低维 `\theta` 的真值恢复、梯度检查、参数相关性分析和多初始化测试，再进入真实数据。

比较 `FIXED / RAW / KF / RTS / MARG`，同时比较是否使用标定后的有效天线响应。训练轨迹和测试轨迹必须预先分开；不得依靠逐包自由复增益掩盖不可辨识问题。

只有当前述方法稳定后，才考虑深度约束联合优化、EKF/UKF、因子图或学习模型。

### 阶段 6：真实实验与消融

真实实验按“先控制、后放开”组织：

1. 固定硬件和无人参考，估计硬件、装配与环境漂移下限；
2. 固定人员、衣物和稳定器装配，只改变人体三维几何；
3. 比较正确几何、固定几何、时间错位几何和他人几何；
4. 比较标量距离、三维几何和是否传播协方差；
5. 在固定几何下更换人员或衣物，评估前置深度无法消除的 `w_human`；
6. 最后加入直接手持和不同握姿，作为第二阶段压力测试。

每个条件应多轮重复并随机化顺序，以避免时间漂移与实验条件绑定。

## 6. 评价与判定

仿真阶段主要评价：

- CSI 幅度与相位残差；
- 环境参数误差 `E_\theta`；
- 人体三维位置和距离误差；
- 不同初始化和重复实验的稳定性；
- 留出轨迹误差与协方差覆盖率。

真实阶段主要评价：

- 留出位置或轨迹上的 CSI 预测误差；
- 跨轨迹、跨 session 的 `\theta` 一致性；
- 整机幅相响应与有效方向图的重复性；
- 优化失败率、异常梯度和误差预算；
- 前摄跟踪精度、有效率和延迟；
- 设备 BOM、部署步骤、便携性和采集效率。

不能只用训练残差下降证明方法有效。真实材料参数没有精确真值时，应以留出预测性能和跨 session 参数一致性为主要依据。

## 7. 里程碑与停止条件

| 里程碑      | 通过条件                                                     | 未通过时的处理                       |
| ----------- | ------------------------------------------------------------ | ------------------------------------ |
| M0 可行性   | 手机、CSI、冻结装配和前向模型均有可执行路线                  | 更换接口、硬件或限定传播模型         |
| M1 科学假设 | 忽略人体动态几何会污染`\theta`，深度条件方法在测试轨迹改善 | 降低人体几何主线优先级               |
| M2 人体几何 | 精度、有效率和不确定度达到预设门槛                           | 改用外部深度、侧拍先验或统计扰动     |
| M3 CSI 闭环 | 链路语义明确、字段完整、连续稳定且装配可重复                 | 更换 CSI 硬件或先完成仿真研究        |
| M4 数据闭环 | 时间、坐标、房间模型和标定版本统一                           | 限制速度、缩短 session 并重新标定    |
| M5 算法有效 | 深度条件方法优于固定人体基线，并泛化到留出数据               | 检查人体模型、天线校准和参数可辨识性 |
| M6 真实闭环 | 测试残差或跨 session 的`\theta` 一致性显著改善             | 如实报告 sim-to-real gap             |

## 8. 当前最高优先级

1. 冻结并编号手机—稳定器和网卡—天线—主机两端装配；
2. 完成支架、稳定器和直接手持三组静态 CSI 重复性预实验；
3. 跑通后摄世界位姿、前摄人脸锚点和时间戳的 10 分钟采集；
4. 完成多个已知距离下的前摄静态测试和连续行走有效率测试；
5. 复现 LOS/CIR/CFR，并单独检查一次反射、人体参数化和有限差分梯度；
6. 完成动态人体几何是否影响 CSI、是否污染低维 `\theta` 的最小仿真；
7. 确认 CSI 硬件与 PicoScenes 环境，跑通手机上行帧筛选；
8. 建立统一 session 数据格式、静态参考段和标定版本记录；
9. 准备真实房间模型的来源、尺度验证和首版材料区域；
10. 建立设备 BOM，并准备与可比 USRP/SDR 方案的成本和部署对照。

## 9. 预期贡献

最终论文贡献应由实验结果决定，候选贡献为：

1. 定量揭示动态人体—设备几何对 CSI 和静态环境参数反演的系统性影响；
2. 提出将前置深度人体几何及其不确定度传播到可微射线追踪的参数反演方法；
3. 构建物理链路、时间和坐标语义严格的商用手机多模态无线数字孪生采集框架。

“低成本”、完整多径、自然手持适用性和跨人员泛化均需单独证据支持。在证据不足时，应缩小结论范围，不作超出实验条件的表述。
