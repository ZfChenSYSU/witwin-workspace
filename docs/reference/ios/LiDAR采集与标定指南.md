# iPhone LiDAR 采集与标定指南

更新时间：2026-09-09

本文规定带后置 LiDAR 的 iPhone 在本项目中的采集与标定方法。具体字段和文件角色
应进入 `schemas/session-format/`；本文只说明操作与验收原则。

## 设备预检

首次使用目标设备时记录型号、硬件标识、iOS、App 版本、可用容量和热状态，并在
真机上检查世界跟踪、前置人脸跟踪、场景深度和场景重建能力。能力存在不等于多项功能
能够按项目所需配置并发运行，必须再做最小录制验证。

## 数据角色

- RGB 与相机内参：纹理、颜色、视觉对照和投影模型；
- ARKit 相机位姿：手机在 ARKit 世界坐标中的米制轨迹；
- 场景深度与置信度：逐帧局部深度观测和质量信息；
- 场景网格或 RoomPlan：系统累计或结构化的房间几何；
- CoreMotion：运动质量检查和独立传感器记录；
- 前置人脸或深度：人体—手机几何，不能与后置房间 LiDAR 混为同一数据流；
- UDP 日志：手机与 CSI 端时间映射及链路追溯。

## 采集要求

1. 开始前记录装配编号、相机/LiDAR 配置、人工尺寸真值和房间标记。
2. 保留 RGB、深度、位姿和网格的原始时间戳、帧标识、单位、坐标与质量状态。
3. 缓慢移动并覆盖墙角、门窗和主要传播表面，包含起止静止段与空间回环。
4. 记录低纹理、反光、透明、远距离、遮挡、快速移动、重定位和热降频等异常。
5. 停止后先完成文件封装、校验和与完整性报告，再导出整个 session。

## 标定与精度检查

- 验证深度内参、RGB 内参以及深度到 RGB/后置相机的外参方向和单位；
- 使用已知平面检查深度偏差、噪声、孔洞和视角依赖；
- 使用至少一组独立尺寸检查房间尺度、墙面平整度和夹角；
- 检查 RGB—深度投影重合以及网格—相机轨迹的一致性；
- 手机—保护壳—夹具—稳定器装配改变后，重新评估相机—天线外参和无线响应；
- 前置人脸—胸腔标定单独执行，不由后置 LiDAR 房间精度代替。

## 首轮验收

- 所声明的传感器流都能被实际解码，时间戳单调且缺口可解释；
- 任一 LiDAR 样本可回溯到对应相机位姿、标定和质量状态；
- 原始数据保持不变，派生滤波、补洞和网格化结果使用不同文件角色；
- 人工尺寸、平面误差、覆盖率、孔洞率和重复扫描差异有量化报告；
- 导出的最小 session 能通过服务器导入检查。
