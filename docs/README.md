# WiTwin 文档中心

`docs/` 是本仓库科研计划、进度、实验报告和长期参考资料的唯一权威入口。

## 目录结构

```text
docs/
├── current/      当前仍在维护的主计划、总进度和分支状态
├── history/      已完成阶段、旧版本计划、带日期报告和环境交接
└── reference/    长期有效的使用指南、工作流和技术调研
```

代码目录可以保留简短的 `README.md` 说明运行入口，`schemas/` 也可以保留与格式实现共同演进的协议规范；除此之外不得再存放独立的进度报告或科研结论文档。实验脚本、数据和图像继续留在 `pipelines/`，相应报告统一归档到 `docs/history/`。

## 快速入口

- [项目当前进展与下一步方向](current/项目当前进展与下一步方向.md)

## 文档维护规则

1. `current/` 中的文件采用无日期文件名，内容随进展原位更新。
2. 总体计划放在 `current/project/`；各工作分支的最新状态放在 `current/branches/`。
3. 一项阶段工作结束后，将详细报告以带日期或实验名的文件归档到 `history/`，并更新对应的当前状态文档。
4. 历史文档默认不继续修改；如需纠正事实，应明确写出修订说明。
5. 长期操作指南和技术调研放入 `reference/`，不与阶段进度混放。
6. 新文档优先链接已有证据，不复制实验数据或重复维护多份当前结论。
7. `workspace/host_snapshot/` 是原始快照，不属于当前文档体系，也不得为整理文档而修改。
