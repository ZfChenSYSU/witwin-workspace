# 视频 SLAM 与房间三维重建

此目录用于 WSL/GPU 端的后置视频重建流水线，对应工作分支
`work/wsl-witwin`。

## 输入

- iOS 端后置视频或逐帧图像；
- ARKit 帧时间戳、相机内参、图像尺寸和 tracking state；
- ARKit 米制相机位姿；
- CoreMotion IMU；
- session 元数据和校验和。

## 基线流程

```text
质量检查与关键帧选择
  -> 顺序特征匹配与视觉 SfM
  -> 视觉轨迹与 ARKit 米制轨迹 SE(3)/Sim(3) 对齐
  -> 多视图稠密点云
  -> 平面正则化、网格化与材料区域标注
  -> 导出 WiTwin 可使用的统一房间坐标模型
```

第一版建议以 COLMAP 为可解释基线。人工测距、标定物或其他扫描设备只作为独立
精度真值，不替代视频和传感器重建成为模型主要来源。

后续代码应从 `schemas/session-format/` 读取统一字段，不在本目录复制一套独立
时间戳或坐标约定。
